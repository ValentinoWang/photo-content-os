# 08.01 只有 tags / 灵感 / 想法：从信号到项目包

> 情形编号：`08.01`。  
> 适用情形：现在只有 tags、灵感、一句话想法、截图或口头表达，还没有确定本地素材批次，也不一定已经立项。

## 输入

```text
tags
一句话灵感
情绪触发
想表达的观点
可选：截图 / 照片 / 视频附件
```

## 用哪个能力

| 目的 | 能力 |
| --- | --- |
| 只是归档灵感 | `【灵感】` |
| 把灵感整理成可做内容 | `【创作-灵感】` |
| 先判断值不值得做 | `【创作咨询】` |
| 上传素材后直接要定位和初稿 | `【素材创作】`、`【素材创作-小红书】`、`【素材创作-抖音】` |

## 推荐输入

```text
【创作-灵感】
tags：#毕业典礼 #清华 #第一视角 #黄领 #校园
灵感：想做一条第一视角体验清华毕业典礼的视频，强调“学业副本结算完毕”。
已有素材：稍后会放入 Mac Inbox 批次。
目标平台：抖音 / 小红书
```

## 云端应该沉淀什么

```text
01_idea_card.md
= 为什么值得做

02_project_brief.md
= 面向谁、表达什么、成功标准是什么

04_script.md
= 初稿脚本或内容结构
```

## 不要做

```text
不要把真实照片、视频、Live Photo 或 360 原始素材上传到云端当素材盘。
不要在没有本地素材绑定线索时直接创建 Mac ready task。
不要用【创作咨询】替代项目文件写入。
```
