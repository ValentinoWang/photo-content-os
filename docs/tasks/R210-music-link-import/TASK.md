### 3. 入库

- 位置：素材根下 `library/music/`，经 `runtime_paths.local_media_root()` 取，不写死路径。
- 每首一个文件夹：音频原文件，加一份 `track.json`。`track.json` 写：歌名、歌手、专辑（有就写）、来源平台、平台曲目编号、原链接、导入时间、时长、采样率、文件哈希。

- **去重**：联网之前先按「平台 + 曲目编号」查库，已在库里就直接提示「已在库里」，不联网。下载之后再按音频哈希查一遍，同一首从不同平台进来的，也在 `track.json` 里互相标注。

`python scripts/import_music.py "<分享文字或链接>" [更多链接…]`，一次可以导入多条，每条单独报结果：「已入库 / 已在库里 / 失败：原因」。另加：

## 阶段 2b（2026-10-19 Claude 看完 REPORT-2 后定）

### Claude 查到的根因

- 本机出口 IP 在**台湾**（台北，中华电信），用户目前人在台湾。
- 网易云《Turn Back Time》的详情 `privileges`：`st=-100`、`pl=0`、`dl=0`、`freeTrialPrivilege.cannotListenReason=1`；`chargeInfoList` 里 128k、192k、320k 的 `chargeType=0`，说明这首是免费曲。`st=-100` 是**地区限制**（大陆以外 IP），不是会员限制，也不是没有版权。
- 汽水音乐只在大陆运营，取歌曲页时连接失败，很可能同样是地区原因。
- 用户的大陆服务器 `ubuntu@106.52.146.37`（广州电信）SSH 可用，出口在大陆。**要不要用它当出口，等用户决定，本阶段不要连它。**

### 要做的

1. **抖音**：修好缓存把 `/share/note` → `/note` 两次跳转合并成同一节点的 bug。HTTP 层按实际 URL 缓存，曲目身份的去重留在业务层。补回归测试。然后对**从没请求过**的作品页发**一次**匿名请求（不带 Cookie），取作品的音乐并入库。必要时用移动端 UA 直接取 `iesdouyin.com/share/note/<id>` 的服务端渲染数据，你按 douyin-downloader 的做法定。
2. **地区限制要说清楚**：网易云遇到 `st=-100` 或 `cannotListenReason=1` 时，报「网易云限制了你当前所在地区播放这首（你现在的网络不在大陆），需要从大陆网络导入」，不要再报「暂无可用音源或版权」。汽水音乐的网络失败要记下异常类型（超时、连接重置、TLS 等），写进尝试记录，判断是不是地区原因。

4. **出口代理（只做配置，不连）**：给平台请求加一个可配置的代理（例如环境变量 `CONTENT_OS_MUSIC_PROXY=socks5h://127.0.0.1:<端口>`），只作用于音乐导入的请求，默认不开。README 写清怎么用 SSH 动态端口转发（`ssh -N -D <端口> <服务器>`）配合它。代理配了但连不上时要**明确报错**，不许退回直连。
5. 写测试：地区限制报文的识别、代理连不上时报错而不是直连、抖音跳转缓存回归。
