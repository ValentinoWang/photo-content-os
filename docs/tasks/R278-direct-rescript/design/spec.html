R278 实现说明（给 Codex）

需求卡「脚本直出先定视频风格，生成过以后能回到分镜脚本改了重新生成 · 待确认（R278）」的实现细节：交互规则、所有状态（逐块，文案合同从这里取）、设计编号、文案表、数字公式和接口、门禁。给用户看的改前改后和演示在 index.html。标「R282」的部分属于另一张卡「中台交过来的分镜和配音直接进脚本直出」，在 R278 之后做。

1 交互规则

  1. 版式：第一屏和改分镜脚本一屏自上而下都是整行：分镜脚本 → 视频风格 → 「点「生成」以后」和「配音」并排两张卡 → 生成条（最底下）。原来的右栏 340 不要了；「生成」从分镜脚本框的底部挪到生成条，框底部只留说明和「导入分镜文件」。≤960 宽时视频风格的左右两半、下面两张卡都上下排，分镜脚本表横向滚动。
  2. 分镜脚本表（和中台「分镜脚本」同一张表，列名一字不差）：标题「分镜脚本」+ 一句「每镜写台词，就是配音要念的话；画面、字幕、景别 · 运镜不写，由 Opus 定。」，右边「〈n〉 镜 · 约 m:ss」（时长按中台配音时不写「约」）。六列：
    • 镜头：镜号 + 起止时间「0:00–0:18」，不能改。有中台配音且台词没改过时按配音时间；否则按台词每秒 5.1 字从 0 往后累加。
    • 画面：左边画面图 72×128（9:16），右边来源小标签 + 画面说明（空着时浅灰占位「写这一镜画什么（可不填）」，点进去就能写）。画面图三种：中台交过来带的图（标签照中台：代码渲染 / 参考关键帧 / AI 示意 · 非实拍 / 原片截帧 m:ss，版权待确认的后面接「· 待确认」并用警示色）；生成过的这一镜动画（改分镜脚本时显示；不标来源，因为这一屏的画面都来自现在这条，用户 2026-10-27 定去掉原来的「这一版」标签）：和成片里这一镜同一段画面，静音、循环、自动播放，没有播放按钮；只播在屏幕里的镜，滚出去就停；系统设了减少动态效果时停在关键帧不播；读屏不报；片段读不到时换成关键帧；都没有时虚线框「还没有画面」。点画面图放大（静图、动画都能点，「还没有画面」不能点）：在画面图右边弹出 270×480 的浮层接着循环播放，上面写「第 NN 镜 m:ss–m:ss」和「关闭」；按 Esc、点浮层外面、点「关闭」、滚动页面都会关上，关上后焦点回到那张画面图；点另一镜的画面直接换成那一镜；减少动态效果时浮层里不自动播，带播放控件。中台交过来的只有静图（交接包里没有动画），生成过以后才是动画。
    • 台词：必填，配音要念的话，时长按它算。
    • 字幕 / 花字、景别 · 运镜：可不填；写了 Opus 照着做（字幕 / 花字是画面上要出现的字，景别 · 运镜是构图和动法），颜色、字号仍以全片设计为准。
    • 音乐 / 音效：可不填，表头小字「暂不进成片」；这一轮只保存、随任务带着，成片里没有音乐音效。
    每格直接改（随字数自动长高，不出滚动条），空格子显示「—」。台词里按回车＝从光标处拆成两镜，画面图、画面说明和其他列留在前一镜，新一镜别的列空着（输入法正在组字时的回车不算）；光标在台词开头按退格＝并到上一镜，各列文字用「；」连起来，画面图用前一镜的；粘贴带换行的台词按行拆成多镜、空行丢掉。别的列里回车只是换行。台词空着的那镜生成时不发出去。底部一句「台词里按回车拆成两镜，台词开头按退格并到上一镜 · 时长按中台的配音 / 按台词每秒 5.1 字估」+「导入分镜文件」。还没有内容时没有表，只有一个粘贴框（高 220，占位例句），底部「还没有分镜脚本。可以粘贴台词、导入分镜文件，或从中台交过来。」
  3. 从中台交过来（R282）：这件作品在中台点了「交给我的电脑」或「合成配音并交给本机渲染」、交接包已经落到这台电脑（和「按脚本做视频」读的是同一份），而且这件作品还没生成过时，第一屏直接按交过来的分镜填好六列和画面图，表头下一条浅色横条「从中台交过来：「〈作品名〉」第 〈n〉 版 · 〈时间〉 · 带配音（〈音色〉 · m:ss）。在这里改只存在本机，不会改中台的分镜。」（没带配音就不写括号那段）。带了配音时，「配音」卡变成「配音（从中台带过来）」「〈音色〉 · m:ss。生成时按这条配音实测每一镜的时长，动画比配音长的镜会自动改短。」+「换一个配音…」，生成时直接用这条配音，不用再上传。页头说明「中台交过来的分镜和配音都已带上。检查一下，改完就能生成。」
  4. 中台又交过来新版本（R282）：已经生成过、中台后来又交过来更新的版本时，改分镜脚本一屏的表头下一条横条「中台又交过来新的分镜：第 〈n〉 版 · 〈时间〉。」+ 文字按钮「换成中台这版」：点了整张表和配音换成中台那版（在这里改过的字会被替换），不点就照旧用这条的分镜。
  5. 改名：「脚本直出」页里所有「口播稿」都改成「分镜脚本」（步骤条第一格、入口「改分镜脚本」、页头、空状态），见第 4 节；每镜的那句话按中台叫「台词」。不改：镜详情里的「口播「…」」（R277）和剪辑交接页（真人口播的工作流）。
  6. 入口：有任务、而且任务已经停下来时（同轮询的结束条件，再加 R277 的看图和改镜没在跑），步骤条第一格「分镜脚本」整格是一个按钮，右边写「改分镜脚本」；Tab 能聚焦，读屏名称「改分镜脚本」。任务在跑时这一格不可点，右边灰字：在合成写「合成完才能改」，其他写「写完才能改」。
  7. 改分镜脚本一屏：分镜脚本表预先填好这次的每一镜（台词、画面说明、字幕 / 花字、景别 · 运镜、音乐 / 音效照任务里存的，老任务只有台词），画面是这一版每镜的动画（循环播放），滚到最上面，光标在第 01 镜开头。步骤条第一格是当前步，第二格「生成后从头写」，第三格「生成后重新合成」。页头「改分镜脚本，重新生成」，一句说明，右边「回到现在这条」（不发请求，原样回去）。视频风格默认沿用这条。
  8. 视频风格 · 头部：标题「视频风格」，一句「Opus 在这个风格上写每一镜。先定好风格，才能生成。」，右边分段按钮「选现成的风格」「从头定风格」（原「沿用一条成片的风格」改名，因为现成的风格以后还有风格库）。切换时两边各自写的字都保留。
  9. 选现成的风格：左半边上面一组「这台电脑上做过的」，把 GET /api/direct/styles 的每条都排成卡片（首镜关键帧 45×80、作品名、时间、四个色块），点哪张选哪张；当前任务那张时间前写「这条 · 」。下面「在这个风格上改哪里（可不填）」多行框。右半边是选中那条的大预览：首镜关键帧 180×320、四色（带名字）、字号、动作规矩（短白话）、「不用」小标签。
  10. 风格库（R283）：「这台电脑上做过的」下面再一组「风格库」，小字「样张都是同一段台词」，九张卡片顺序固定：扁平插画、数学动画、极简发布会、手绘白板、赛博故障、水墨国风、数据可视化、8-bit 像素、代码录屏。卡片和做过的一样（样张最后一帧 45×80、名字、四个色块），没有时间那一行。点一张就选中，和做过的成片同一组单选（两组里只能选中一张）。右半边：样张动画 180×320（静音、循环、自动播放，和分镜脚本表的画面同一套播放规则），下面「样张 · 同一段台词」，旁边标题「风格库 · 〈名字〉」+ 四色、字号、动作规矩、不用。「在这个风格上改哪里」对风格库同样有效。生成条写「风格：风格库「〈名字〉」」，写了改哪里再接「，改：〈改哪里〉」。生成后全片设计一行写「用风格库「〈名字〉」的风格」。
  11. 从头定：左半边「风格说明」多行框（6 行，可拉高），下面一排提示「可以照这几项写：」+ 六个小按钮「底色和主色」「强调色」「字的感觉」「画面怎么动」「参考什么」「不要什么」，点一个就在说明末尾另起一行写上「〈项名〉：」并把光标放过去。再下面「先定风格」+ 一句说明。右半边先是虚线框「样张会出现在这里」。
  12. 样张：点「先定风格」（没写说明或分镜脚本还空着时灰掉），Opus 定全片设计，再写出第 01 镜、本机渲染关键帧，约 2–3 分钟；右半边是流光「正在定风格 · 已用 m:ss」，说明框变只读。出来后右半边是样张 180×320（下面「样张 · 第 01 镜」）和四色、字号、动作规矩、不用，下面「就用这个」；左半边多出「再改一句（可不填）」多行框和「改」，Opus 在这套设计上按这句改并重写样张（流光写「正在改样张」）。点「就用这个」后右半边标「已选用」，按钮换成「重新定」（回到写说明，说明保留）。没定成写「没定成：〈原因〉」+「重试」。
  13. 生成条：左边一句说明现在用哪个风格：沿用写「风格：沿用「〈作品名〉」〈时间〉」，写了改哪里再接「，改：〈改哪里〉」；从头定已选用写「风格：刚定好的风格（从头定）」；从头定还没选用写「风格还没定好：先点「先定风格」，满意了点「就用这个」」（警示色）。右边「生成」主按钮：分镜脚本至少一镜有字、本机 Claude 可用、风格已定（沿用有选中；从头定已「就用这个」）才可点。
  14. 「点「生成」以后」第一步跟着风格变：沿用不改「全片设计沿用选中的风格 / 不用等」；沿用并改「Opus 先按你写的改全片设计 / 约 1 分钟」；从头定没选用「先在下面定好风格、看过样张 / 点「先定风格」，约 2–3 分钟」；从头定已选用「全片设计用刚定好的风格，第 01 镜直接用样张 / 不用等」。
  15. 生成之后：沿用不改 → 不出现「Opus 正在定全片设计」，直接写镜；沿用并改 → 页头「Opus 正在按你的话改全片设计」，虚线框「在「〈作品名〉」的风格上改：〈改哪里〉。改好以后七镜都照它写。」；从头定 → 用样张那套设计，第 01 镜的字和写样张时一字不差就直接用样张当第 01 镜。全片设计一行紧跟「全片设计」写来源：「沿用「〈作品名〉」的风格」「在「〈作品名〉」的风格上改过」「这次从头定的风格」。
  16. 全片设计一行和风格预览的写法：去掉现在那行没标题的长句和带删除线的小块，改成两行带标题的短白话：「动作规矩」一句（≤30 字，不出现坐标、百分比、毫秒），「不用」一排小标签（每条 ≤12 字，最多 8 条），不划删除线。这两样是 Opus 定设计时另外写给人看的（motionSummary、bannedShort）；带参数的原话（motionRules、banned）照旧只给 Opus 写镜用，页面上不再显示。老任务没有短白话时，「动作规矩」显示原话最多两行，「不用」显示原话每条一个标签、单条最宽 260 超出省略、悬停看全文。
  17. 其他：这台电脑上没有做过的成片时——R278 单独上线时：「选现成的风格」灰掉，默认从头定，左半边写「还没有可以沿用的成片」；R283 上线后：「选现成的风格」照常可点并默认选中，「这台电脑上做过的」一组换成一句「这台电脑上还没有做过的成片，先从风格库里挑一个。」，风格库一张都不预选，右半边虚线框「还没选风格 / 在左边选一个」，生成条警示色「风格还没选：在下面选一个现成的风格，或者从头定」，「生成」灰。同一作品里切分页再回来，写的字和样张都在；刷新会丢（样张文件留在本机）。生成失败留在这一屏，字都不丢；本机 Claude 调不通照现有做法出 DV-UNAVAILABLE。

2 所有状态

每台是 1440 宽浏览器里作品页的主栏（1231 宽），浅色。顶栏和成片区是套了浅色令牌的真实页面截图；其余按现行样式画。每个状态按块标 data-design-state（-steps -head -script -style -opts -gen -design）。最后一台可以点。
