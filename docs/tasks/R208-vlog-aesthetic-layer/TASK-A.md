## A1：实现 + 测试 + 小样本真跑

### 要做的

1. **镜头切分**：对项目里每段视频用 PySceneDetect 切镜头；单个镜头超过 8 秒的，再按动感变化切成 2–6 秒的候选段。
2. **体检**：每个候选段在 20%、50%、80% 处各取一帧，量下面几项。数值全部记下来；起始阈值照 PRD 4.1，**阈值写成配置，不写死在判断里**。

| 项 | 量法 | 起始阈值 |
|---|---|---|
| 糊 | 拉普拉斯方差，跟本项目中位数比 | < 中位数 40% |
| 过曝 / 欠曝 | 亮度直方图两端截掉的比例 | > 25% 像素 > 250 或 < 5 |
| 抖 | 帧间全局运动的高频抖动（光流或 ffmpeg `vidstabdetect`），和平滑运镜区分开 | 自己定，写清依据 |
| 太短 | 时长 | < 0.8 秒 |
| 动感 | 光流强度均值和峰值所在时刻 | 不淘汰，留给阶段 B |

   量不出来（解码失败、帧取不到）的项记成 `unknown`，**不许当成合格**；有 `unknown` 的镜头不进「精选」，单独列出。
3. **照片**：项目里的照片同样体检（糊、过曝欠曝），打美感分，参与去重；照片没有抖动和动感两项。
4. **美感分**：在本机（Apple Silicon，用 MPS 或 CPU）比较 2–3 个候选模型，例如 LAION improved aesthetic predictor（CLIP ViT-L/14 加 MLP）、pyiqa 里的美感模型、DOVER（视频）。每个都记下：
   - 代码许可证和**权重许可证**（分开写，各附来源链接）；
   - 本机每帧耗时；
   - 在样本上的打分分布。
   按效果和速度选，**许可证不作为排除条件**（课程项目、自己用、不商用，非商用权重也可以用），只要保留许可证文件并记下来源；写进汇报并说明理由。权重缓存放在仓库内 `.tools/models/`（被 git 忽略），不放 `~/.cache`。
5. **去重**：同一场景里画面相似的镜头和连拍照片归成一组，只留总分最高的。**先复用**现有的感知哈希分组（`scripts/generate_ai_prompt.py` 生成 `visual-similarity-groups.md` 的那段逻辑）；不够准再加 CLIP 向量相似度（起始阈值 0.92）。不要另写一套平行实现。
6. **看图终选**：
   - 按素材目录（例如 `01_路上奔赴`、校运会、自拍）或场景分组，每组取总分前若干名，做成一张拼图：每个镜头 3 帧加编号。
   - 用 `llm_common` 现有的传图能力交给多模态模型。模型对每个候选给出「精选 / 可用 / 不用」和一句理由，并从全项目里选 5 个「开场钩子」候选。
   - 模型只能引用拼图里出现的编号；回答里出现不存在的编号要报错，不许静默丢掉。
   - 推理强度先用 medium，记下每次调用耗时；改成别的强度要写理由。
7. **产出**：写到 `<项目>/ai-analysis/shots/` 下：
   - `shots.json`：每个镜头和照片一条，含来源相对路径、区间、各项数值、美感分、去重组、淘汰理由、模型结论和理由；
   - `sheets/`：拼图；
   - `overview.html`：给 Claude 看的证据总览，不是产品界面，朴素即可。按「精选 / 可用 / 不用 / 被淘汰 / unknown」分栏放缩略图、数值和理由。

   素材路径一律经 `runtime_paths.local_media_root()`；JSON 里只写相对路径。

### 接口

一条命令跑完整个项目，例如 `python scripts/select_shots.py <项目目录> [--limit-videos N] [--limit-photos N] [--skip-llm]`。
脚本和模块怎么拆你定，但必须能被阶段 B 复用（阶段 B 会读 `shots.json` 排节奏）。`shots.json` 写 JSON Schema 放进 `schemas/`。
