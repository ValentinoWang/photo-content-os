## 数字公式（写成门禁，按公式核对页面）

- 镜头的有效状态：用户在 `decisions.json` 里有决定就用决定，否则用 AI 结论。「看图没做完」时，没有结论的镜头不计入任何一栏。
- 精选 N = 有效状态为精选的镜头数；可用、不用、淘汰同理；四栏之和 = 已有结论的镜头数。
- 串起来时长 = 精选视频镜头时长之和 + 精选照片数 × 2.5 秒；显示成「分:秒」，四舍五入到秒。
- 场景标题「N 条可用 · 共 M 条」：N = 该场景当前分栏的镜头数，M = 该场景全部镜头数。分栏标签和场景筛选的数字同一口径。
- 「第 i / N 个精选」：i = 精选顺序里的位置，从 1 开始。播放器时间 = 前面所有镜头时长 + 当前播放时间。
- 作品卡、作品页步骤 1：视频数、照片数 = `media-manifest.json` 里 video、image 的条数。「已出 N 版」= `output/` 下含 mp4 的 `v*` 目录数。
- 「正在挑」的进度 = 进度文件里的已完成数 / 总数，按实际值，不估算。
- 项目卡：作品数；等你过目数 = 该组里有结果、未确认、不在跑的作品数；出过成片数 = 已出版本 ≥ 1 的作品数。项目页副标题 = 组数 · 作品总数。
- 工作台角标 = 「等你处理」条数 = 待过目作品数 + 未通过的诊断项数。
- 整理台空状态三个数：作品数、各作品视频数之和、照片数之和（同 `media-manifest.json` 口径）。
- 音乐库：全部 = 库里曲目数；各平台数 = 该平台曲目数；时长按音频实测四舍五入到秒；导入时间按本机时区显示。
- 设置「存放位置」：项目数、作品数同项目页；音乐库首数、素材库项数同各自页面。诊断环 = 通过项数 / 检查总数。
