Studio 浅色界面

需求：「我觉得这个主题太黑了」→ 整个 Studio 换成浅色。做法是把 studio/static/styles.css 里的颜色令牌换成浅色值，再把 styles.css、workflow.css 里约 40 处写死的深色改掉；页面结构、字号、间距都不动。视频画面区（播放器、关键帧、成片）保持原样。下面每组左边是现在，右边是把 light.css 套到真实页面上的截图（临时 Studio，这台电脑数据的克隆）。

3 写死的颜色

  1. 按 light.css 「写死颜色」两节逐条改：能换成令牌的换令牌（侧栏、悬停、标签、提示框、步骤圆点、轨道底），主按钮和品牌标的字改白色，主按钮悬停 #18767E。
  2. index.html 的 <meta name="color-scheme"> 改成 light，表单控件和滚动条跟着变浅。
  3. 保持深色：.handoff .stage（视频预览区）、播放钮、成片播放器、关键帧图本身。

4 门禁

  1. 新测试：styles.css 的 :root 令牌等于本页第 2 节的值；styles.css、workflow.css 除允许的视频区规则外不再出现深色字面量（亮度低于 30% 的颜色）。
  2. 所有页面的正文和次要文字对底色对比度 ≥ 4.5（--ink-3 对 --panel 是 5.3），--ink-4 只用于占位和说明小字（≥ 3）。
  3. 各前端门禁的截图全部重拍；设计合同（文字、编号）不受影响。
