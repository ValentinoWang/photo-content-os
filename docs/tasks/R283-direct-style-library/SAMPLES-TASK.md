# R283 风格库样张任务单

## 背景

脚本直出（R276）的「视频风格」要加一个**风格库**：九种现成风格，用户不用自己写说明，点一张就能用。九种风格改写自开源仓库 Moessif/code-video-showcase（MIT）的风格配方。配方原文在：

`（配方原文：Moessif/code-video-showcase 仓库的 references/style-recipes.md）`

那个仓库做的是横屏、3 秒一段的卡点炫技片。我们做的是**竖屏知识口播**：一条片子用一种风格，一镜跟着一段口播走。所以每种风格要做两件事：

1. 写一张**样张**：用我们自己的渲染器，把同一段台词画成这一风格的一镜。卡片上放的就是它的最后一帧，预览里放它的动画。
2. 写一份**全片设计**：格式和我们现有的全片设计一样，后面 Opus 写每一镜时照它画。

九种风格都画同一段台词，这样用户能一眼比出风格的差别。

## 样张内容（九种都一样）

- 台词：有个经典实验：让学生穿件尴尬的衣服走进教室。穿的人估计，约 50% 的人会注意到；实际只有约 25%。别人的注意，远比我们以为的少。
- 时长 `const D = 12`（360 帧，30 帧每秒）。这是估算时长，所有元素在 0.7·D = 8.4 秒前出完，之后停在完整画面上。
- 页眉：眉题「聚光灯效应」，标题「真有那么多人在看？」（问号用 `.fw`）。页眉的样子按这一风格画。
- 主画面：用这一风格的画法讲清「以为约 50% → 实际约 25%」：先出「以为」，再出「实际」，差值最明显。最后一行小字「Gilovich 等，2000」。

## 硬规则（最容易踩的几条）

- 规则文件里「渲染器硬规则」全部照做：1080×1920、`window.seekFrame`、`data-role="header"`、底部 y ≥ 1536 不放字和关键图形、两侧 ≥ 72px、正文 ≥ 44px、标签 ≥ 34px、中文全角标点。
- 代码里**任何地方**都不能出现 `url(`：所以 SVG 的渐变、滤镜、裁剪、遮罩不能用 `url(#id)` 引用。要渐变、纹理、发光、噪声，就用 `<canvas>` 画。
- 页面上的字都会被强制成华文黑体 Medium 一种字重。canvas 上写字用字体名 `PCPinned0`。手写字、书法字、像素字这类专用字体都没有：像素字可以自己用小方块画；手写感靠线条抖动；书法感靠排版（竖排、印章）。
- 不许 `Math.random`、`setTimeout`、`setInterval`、`requestAnimationFrame`；要随机就用固定种子的函数（例如 mulberry32）。同一帧永远画出同一张图。
- 单文件少于十万字符，不读任何外部资源。

## 从配方改什么、留什么

- **留**：调色板、构图语言、图形画法、技术手法、整体观感。用户看卡片要能一眼认出「这是手绘白板」「这是水墨」。
- **改成竖屏**：主画面撑满内容区（约 y 200–1500），不要照横屏比例缩在上半屏。
- **动法改成跟口播**：去掉卡点冲击（白闪、整屏缩放、抖动、砸入）和 3 秒节拍。改成随台词一句一句长出来：一镜一个主动作，字在被读的时候不动，数字跳 1.2–1.6 秒后停住。风格自己的标志动作可以留，但只在元素出场时用一次，不能一直动。比如手绘的逐笔画出、故障风的出场错位、像素风的逐格出现。
- **不要**展示片自己的标签：左上「0X 风格名」胶囊、右下倒计时、品牌水印、`STYLE 0X / 11`。
- 规则文件「默认禁用」里和这一风格本身冲突的条目可以不守。比如赛博故障就是霓虹，水墨就是米白纸底。这一风格自己的「不用」写进全片设计里，代替默认禁用。

## 每种风格的产出

1. `docs/tasks/R283-direct-style-library/samples/<id>.html`：样张代码。
2. 跑 `docs/tasks/R283-direct-style-library/render_sample.sh <id>`。这个脚本会做四件事：
   - 先跑规则检查，有 ERROR 就停；
   - 渲染 360 帧；
   - 出卡片图 `lib-<id>.jpg` 和小片段 `lib-<id>.mp4`，放到 R278 稿子的 `img/` 里；
   - 出一张六帧联系表，分别取 0、2、4、6、8.3、12 秒。
3. 用 Read 工具**逐张看**联系表和最后一帧原图。不合格就改了再渲染，每种最多三轮。合格线：
   - 一眼认得出是这一风格，和配方写的观感对得上；
   - 字没有被切、没有挤出画面、没有叠在一起；
   - 第 0 帧就有页眉和主图雏形，不是空屏；
   - 最后一帧是完整的画面，内容区没有下半屏一大块空着；
   - 「以为约 50% → 实际约 25%」看得懂。
4. `docs/tasks/R283-direct-style-library/samples/<id>.json`，格式如下，字段名照写：

```json
{
  "id": "whiteboard",
  "name": "手绘白板",
  "recipe": "04 手绘白板",
  "palette": {"background": "#f4efe6", "primary": "#2a2724", "accent": "#c0392b", "neutral": "#8a8580"},
  "typeScale": [168, 72, 44],
  "motionSummary": "边讲边画，一笔一笔画出来，画完就停",
  "bannedShort": ["渐变", "发光", "三卡并排"],
  "motionRules": "给 Opus 写镜用的完整动作规矩，可以带参数（时长、幅度、先后）。",
  "banned": ["给 Opus 用的完整不用清单，一条一句，写清为什么"],
  "visualGrammar": "给 Opus 用的形式说明：底色、主色和强调色各标什么、页眉样子、图形怎么画（线条、填色、纹理）、构图、标志动作、一屏放多少东西。照这段能画出同一风格的任何内容。",
  "adapted": "和配方原文比改了什么（竖屏、动法、字体、去掉的技术），一两句。"
}
```

- `motionSummary` 不超过 30 字，`bannedShort` 每条不超过 12 字、最多 8 条。这两样是给用户看的白话，不出现坐标、毫秒、百分比。
- `palette` 四个色是全片设计的四色，背景、主色、强调色、中性色，用样张里真用的颜色。
- `typeScale` 是样张里真用的三级字号：数字或大字、标题、正文。
