1交互规则

  • 入口：作品页分页「按素材剪 vlog · 按脚本做视频 · 脚本直出」，网址 #view=piece&piece=<作品>&ptab=direct。这件作品有过直出任务时，进来直接显示最近一个任务的样子；没有就是粘贴口播稿的第一屏。
  • 步骤条三步：口播稿 → Opus 写每一镜 → 成片。只显示，不能点（三步都在这一页里）。
  • 粘贴口播稿：一行一镜，空行忽略。粘贴后下面马上列出分好的镜和每镜估算时长；没有内容时「生成」灰掉。「导入分镜文件」读上游中台导出的 storyboard.json，按每镜口播填进文本框。
  • 模型：右上角写「Opus 5.5 · 本机 Claude」。本机 Claude 调不通时变黄点，页面出提醒块（「本机 Claude 调不通」状态），「生成」和「重写」都灰掉。
  • 生成以后：先出「全片设计」一行（四个颜色、字号、动作规矩、不用的套路），再出七镜胶片。每张卡的状态：等着写 → 正在写（显示已写多久）→ 写好（显示从点生成起第几分钟写好）；自查没过时显示「自查没过，正在重写」，第二次还不过显示「写了两次都没过」，页面顶部出红色提醒块。
  • 轮询：任务没结束时每 2 秒取一次任务；全部结束（写好、失败或成片出来）就停。页面离开再回来，从任务接着显示，不重新开始。
  • 选中一镜：点卡片，下面展开这一镜：大关键帧（后端渲染的 JPEG；Studio 的安全策略不允许在页面里运行 Opus 写的代码，所以不做拖帧和播放）、口播原文、时长、写了几次、主动作、代码字数、检查结果、修改意见、看代码。默认选中第一张需要你看的卡（失败的 → 正在重写的 → 第 01 镜）。
  • 重写一镜：写一句修改意见（1–200 字）点「让 Opus 重写这一镜」。只这一张卡变成「按你的意见重写」，其他卡的画面和写好时间一个字都不变；重写期间这一镜的输入框和按钮灰掉。
  • 配音：「上传配音…」选 WAV。上传后按配音实测每镜时长，动画比配音长的镜自动重写一次。没有配音时合成按钮叫「先合成无声预览」，有配音叫「合成成片」。
  • 成片：页面里播放（竖屏 288×512），下面七镜缩略条，点哪镜跳到哪镜；右边写时长、镜数、带不带配音、四项检查。「在访达中显示」打开成片所在文件夹。
  • 2026-10-26 F1 后的改动（总控定）：加「读不到任务」「合成无声预览」「无声预览出来了」三个状态；占位例句改成「清华 AI 体育博主」；去掉没有接口的「停下来」「在访达中显示」和编造的合成帧数、剩余时间；无声预览的声音检查写「无声预览，不检查声音」。
  • 减少动画：系统设置「减少动态效果」时，「正在写」卡片的流光不动，只留文字。

6数字公式

数字怎么算
每镜估算时长口播字数（含标点）÷ 5.1，一位小数；上传配音后换成实测（measuredSeconds）
合计时长 m:ss各镜时长相加，四舍五入到秒
x / N 镜写好状态是「写好」「正在渲染」「渲染好」的镜数 / 总镜数
已用时间现在 − 任务 createdAt；卡片上「写好 · m:ss」= writtenAt − createdAt，重写后只这一镜变
正在写 · 已写 m:ss现在 − 这一镜开始写的时间
关键帧这一镜 0.8 × 时长那一帧，短边不超过 360
合成进度已拼帧数 / 总帧数；总帧数 = 合计时长 × 30
七镜一排的宽度1440 宽：(1440 − 210 − 48 − 6 × 10) ÷ 7 ≈ 160，关键帧 160 × 284；口播两行，每行约 11 字

7门禁（先写好，在现在的代码上会失败）

  • 作品页有「脚本直出」分页，网址 ptab=direct 打开它。
  • 没有口播稿时「生成」是灰的；本机 Claude 调不通时「生成」「重写」都是灰的，页面上有 DV-UNAVAILABLE。
  • 任务没结束时每 2 秒取一次；结束后不再取（门禁数一分钟内的请求次数）。
  • 重写第 03 镜以后，其他六张卡的关键帧地址（含 v=）和「写好 · m:ss」不变。
  • 页面上不出现英文失败代码和本机绝对路径；读取失败写「读不到」，不写成「还没开始」。
  • 不写内联 style=（Studio 的安全策略会拦）：进度条宽度、关键帧缩放用 CSS 变量或脚本设置元素样式。
  • 真实首屏截图：用这件作品真实跑一次的任务，截「写到一半」「七镜写好」「成片出来」三屏，每屏 1440 和 960 两个宽度，逐张交给总控看。
  • 文案比对：check_design_contract.py check 对 contract.json 通过。
