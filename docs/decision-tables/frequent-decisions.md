# 素材高频情形决策表

> 子子文档定位：本文件只承载素材高频情形的放置和流转判断，包括素材保存、iCloud 入库、iPhone 同步、资产库登记、连拍保留和纪念素材。它不是选题、脚本、剪映或发布决策表。执行总纲保留速查入口，详细 SOP 仍分别放在 `docs/` 其他子文档中。
> 编号：`07.01`，隶属 `decision-tables/`。

## 素材去向

| 情形 | 放哪里 | 是否进 iPhone | 是否进资产库 |
| --- | --- | --- | --- |
| 普通项目可用素材 | 项目 L3 内容目录 | 否 | 否 |
| 项目最出彩代表照/视频 | L3 保留源文件，副本进 `80/project-selected` | 是 | 视情况 |
| 封面候选 | `80/cover-candidates` | 是 | 可登记 |
| 超脱项目本身的纪念素材 | L3 保留源文件，副本进 `80/memorial` | 是 | 登记到 `library/memorial` |
| 手机常用复用素材 | L3 保留源文件，副本进 `80/phone-reusable` | 是 | 登记资产卡片 |
| 未来可能复用但手机不常用 | L3 保留源文件 | 否 | 只登记资产卡片 |
| 已加工成通用成品/模板 | `library/对应分类` | 可选 | 是 |
| Live Photo 精选原始组 | `80/live-photo-groups` | 是 | 视情况 |
| Final / 高光回看 | `output/Final`，副本进 `80/final-output` | 是 | 否 |
| 30 张连拍里 5 张出彩 | 出彩 5 张进 L3 + 80 对应目录 | 是 | 视情况 |
| 30 张连拍里 10 张动作略不同 | 放项目 L3，命名为补充/动作变化/情绪备选 | 否 | 否 |
| 30 张连拍里 15-20 张近重复但想保存 | `raw-vault/连拍原始组_保留/组名/` | 否 | 否 |
| 待确认是否入库 | `80/pending-review` | 暂不导入 | 否 |

## 连拍处理

```text
特别出彩
-> 项目 L3 源文件保留
-> 复制精选副本到 80 对应子目录

动作略有区别
-> 项目 L3 内容目录
-> 命名为 补充 / 动作变化 / 情绪备选

近重复但想保存
-> raw-vault/连拍原始组_保留/组名/
-> 不进 iPhone
-> 不进资产库
```

## iPhone 同步判断

```text
想经常在手机看、发、剪、选封面
= 进入 icloud-selected 对应子目录

只是未来可能用
= 不进 iPhone，只写资产卡片或留项目 L3

只是想永久保留但不常看
= 项目归档 + 阿里云盘镜像 + 移动硬盘冷归档
```

## 纪念素材判断

```text
超脱项目本身的人生节点、身份节点、重要关系、重要成果
= 80/memorial
= library/memorial

只对当前项目有用
= 项目 L3 或 80/project-selected
```
