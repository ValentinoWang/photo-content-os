# 规范子文档索引

本目录承载本地素材系统的执行总纲、执行细则和少量日常使用指南。`00_本地素材与剪映HyperFrames流转总纲.md` 保留术语、总口径、素材决策表入口和索引；`01` 到 `06` 子文档承载详细 SOP，`07` 承载素材决策表，`08` 承载按入口场景写成的使用指南。

这里是 Mac 本机执行规则，不放 Obsidian 协议入口。Obsidian 侧的 `06_技术栈与自动化/腾讯云OpenClaw与MAC_OpenClaw本地素材协同流转规范.md` 留在自媒体库中，负责腾讯云 OpenClaw、Mac OpenClaw、项目包和任务队列的交接说明；本地 docs 与它通过 `99_System_OpenClaw/scripts/30_check_obsidian_doc_sync.py` 保持同步。

编号规则：`00` 是本地执行总纲；一级制度子文档使用 `01` 到 `06`；素材决策表目录使用 `07_decision_tables_决策表/`，目录内文档使用 `07.xx`；使用指南目录使用 `08_usage_guides_使用指南/`，目录内文档使用 `08.xx`。其中 `08.xx` 对应具体使用情形，不是普通章节号。
