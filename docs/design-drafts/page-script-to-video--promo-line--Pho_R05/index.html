脚本直出加一种「宣传片」：横屏、按音乐出片

需求卡 Pho_R05 第 5 段。现在的脚本直出只能做竖屏口播：按台词写镜头、按配音排时长。宣传片沿用同一套流程（Opus 写每一镜 → 本机逐帧渲染 → 合成），只换三样：输入从「台词」换成「这一镜要表现什么」，每一镜挑一个镜头配方（124 张，来自 video-shotcraft），时长从「按配音」换成「按配乐的小节」。一共改六处：

  1. 1先选做哪种
  2. 2分镜脚本换成镜头表
  3. 3选镜头配方
  4. 4配音换成配乐
  5. 5镜头卡改横版
  6. 6成片改横屏

4 交互规则
  1. 做哪种：只在还没生成或点了「改分镜脚本」时出现。切到「宣传片」时，镜头表、配乐、风格各自保留上次填的；风格还没选过的，默认选风格库里的「产品界面」。已经生成过的作品，点「改分镜脚本」进来能切换，生成后是一条新的直出任务，原来那条留在本机。
  2. 镜头表：「要表现什么」必填，写了才算一镜；在格子里按回车拆成两镜，开头按退格并回上一镜（和口播的台词格子一样）。粘贴多行文字，一行变一镜。「屏幕上的字」「截图」可以空着。
  3. 镜头配方：每格默认「Opus 挑」。点格子打开选配方弹层：左边按类别筛，右边每张卡鼠标停留时播放样片；选中后点「用这个」，格子显示配方名，旁边带「你选的」。弹层里点「让 Opus 挑」恢复默认。Esc 或点「取消」关闭，不改格子。生成以后 Opus 挑的格子显示「Opus 选的」。
  4. 小节：默认「自动」，按这一镜动画的长度取够用的最少整小节；点 − / + 改成固定 1–8 小节，减到 1 以下回到「自动」。固定小节比动画短时，镜头卡上出现「有提醒」，提醒写「动画 X 秒，N 小节只有 Y 秒，结尾会被切掉」。
  5. 截图：点「加截图」选一张 PNG 或 JPG（不超过 20 MB），Opus 写这一镜时把它当画面里的界面图用；再点一次可以换，鼠标停留出现「去掉」。
  6. 配乐：只列音乐库里节拍已分析好的歌可以选；还没分析好的灰掉，右边写原因。点歌名左边的播放键试听（同一时刻只放一首）。选中后下面出现小节条：颜色是这首歌的安静、推进、高潮，深色横条是这几镜会占的小节；「从第几小节开始」点 − / + 改，默认是第一段「推进」的开头。镜头表改了，深色横条和总时长跟着变。
  7. 生成条：缺什么按顺序只写一条：镜头表空 → 没选配乐 → 配乐不够长 → 风格没定。都齐了写这次的摘要，「生成」可以点。
  8. 生成以后：步骤条、进度、逐镜重写、画面问题记录、合成都和口播一样；镜头卡是横版，三张一行。点一张卡，下面的详情多一块「镜头配方」，可以「换个配方重写」，打开同一个选配方弹层，选好后只重写、只重渲这一镜。
  9. 合成：配乐从起始小节截取，按小节排好每一镜，结尾淡出 1 秒，峰值压在 −1 dB 以下；宣传片没有「无声预览」，一合成就带配乐。
  10. 减少动画：选配方弹层里的样片不自动播放，只显示封面。读屏：「做哪种」是单选组，读「宣传片，横屏，按音乐，已选中」；配乐列表是单选组，灰掉的行读出原因。

8 给后端的接口要求

 
GET  /api/direct/recipes
  → { recipes: [{ id, name(中文短名，≤8 字), category, summary(一句话), use(适用), seconds(动画秒数), energy(低|中|高), posterUrl, clipUrl|null }],
      categories: [{ key, name, count }] }
  数据来自 scripts/direct_video/shot_recipes/index.json；index 加 name、seconds、energy 三个规范字段（124 张都要有，name 由人审过的中文短名）。
GET  /api/direct/recipes/{id}/poster.jpg   GET /api/direct/recipes/{id}/clip.mp4

GET  /api/review/music  已有；每首加 promoBeat: { status: ready|missing|failed, bars, bpm, sections:[{startBar,endBar,kind:quiet|build|peak}], firstBuildBar, reason? }
  （实现时定名 promoBeat：beat 已被原有的音乐分析结果占用。歌曲编号用已有的 file_sha256，生成请求的 trackId 填它。）

POST /api/projects/{id}/direct/jobs  在现有字段上加：
  kind: "talk" | "promo"            （缺省 talk，旧任务一律 talk）
  promo: { brief, trackId, startBar, fadeOutSeconds: 1,
           shots: [{ visual, text?, recipeId|null, bars: "auto"|1..8, imageId? }] }
  promo 时 storyboard 由 promo.shots 生成；width 1920、height 1080；不收配音。
POST /api/projects/{id}/direct/promo-images  (image/png|image/jpeg，≤20 MB) → { imageId }

job 投影加：kind；promo: { trackId, trackTitle, bpm, startBar, endBar, seconds }；
  shots[].recipe: { id, name, chosenBy: "user"|"opus" }；shots[].bars；shots[].text
  output.checks 加 barsAligned { aligned, total }、peakDb
POST .../shots/{sid}/rewrite  body 可带 recipeId（换配方重写）

错误码（各配一句页面文字，见第 7 节「出错」）：
  beat_map_unavailable  配乐的节拍图读不到
  track_too_short       配乐不够长（带 needBars、leftBars）
  recipe_not_found      配方读不到
  promo_image_invalid   截图不是 PNG/JPG 或超过 20 MB
合成：走 scripts/direct_video/promo_plan.py（排期 + 预混一条 WAV）→ 现有 multi_shot.py + compose.py。
