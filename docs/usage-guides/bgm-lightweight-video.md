# 08.06 低技术爆款反抄：BGM 卡点轻量成片

> 情形编号：`08.06`。  
> 适用情形：已经看到一个爆款视频，技术含量很低，不需要完整分镜脚本，只想用相似开头、节奏、BGM 和情绪结构，把本地素材快速剪成一条。

## 先判断是不是轻量路线

满足这些条件，走本指南：

```text
1. 参考视频主要靠 BGM、卡点、标题或情绪氛围成立
2. 镜头逻辑简单，不需要复杂叙事和转场设计
3. 不需要逐镜头复刻运镜、台词、字幕结构
4. 本地素材已经有一批可填空的画面
5. 目标是快速出片，而不是做完整创作方案
```

如果参考视频靠复杂叙事、人物采访、反转、长字幕、剧情推进或多机位动作衔接成立，不走本指南，改看 `08.04`。

## 云端该怎么写

不要把 `【轻量反抄】` 当成新的飞书触发词。默认复用已有 `【创作-再创】` 能力，只在正文里声明 `模式：轻量反抄`。

远端不要写完整 Mac 路径，只写 `batch_id`：

```text
【创作-再创】
模式：轻量反抄 / BGM 卡点
爆款视频链接：xxx
模仿重点：BGM / 卡点 / 开头标题 / 情绪氛围 / 画面顺序
我的 tags：#xxx #xxx
本地素材批次ID：YYYYMMDD_事件名
目标平台：抖音 / 小红书
BGM：原视频同款 / 同节奏替代 / 待剪映搜索
成片长度：15 秒 / 30 秒 / 60 秒
目标：生成轻量剪辑卡，不生成完整 Storyboard 和 EDL
```

这不是新增 Mac 执行能力，也不是新增自动剪辑能力。它只是把已有 `【创作-再创】` 路由到更轻的输出规格：

```text
不要求素材匹配报告
不要求完整 Storyboard
不要求复杂 EDL
不要求 native import pack
只要求轻量剪辑卡 + BGM/卡点参考 + 素材填空建议
```

云端产物只需要：

```text
轻量剪辑卡
BGM / 节奏参考
素材填空建议
标题 / 封面候选
发布文案初稿
```

不需要默认生成：

```text
完整分镜脚本
复杂 EDL
native import pack
长篇素材匹配报告
```

## Mac 本地怎么落盘

真实素材仍然先进：

```text
00_Inbox_Mac_Intake/YYYYMMDD_事件名/
```

如果已经确定要做成片，再进入正式项目：

```text
01_Project_Workspace/主题集合/YYYYMMDD_项目名/
```

参考爆款和 BGM 信息不要塞进 Raw 素材目录，写到：

```text
90_Draft_Project/剪映工程/轻量反抄剪辑卡.md
```

如果你确实有下载好的音频文件，临时放：

```text
项目根/App_WorkCache/BGM临时参考/
```

最终以剪映工程里实际使用的音乐为准。没有版权确认的音频，不进入长期资产库。

## 剪映执行方式

```text
1. 人在剪映里找同款 BGM 或同节奏替代
2. 先把 BGM 放进时间线
3. 按鼓点 / 变奏 / 人声起点切 4-8 个画面
4. 只做必要裁切、变速、调色和标题
5. 导出 V1
6. 跑成片复核或人工快速看一遍
7. 通过后导出 Final
```

输出仍然放：

```text
91_Output/V1/
91_Output/Final/
```

如果只是低技术快速反抄，`V1` 可以直接人工判断，不强制跑完整 `local_output_review`；但 Final 发布前至少检查：

```text
画面不糊
节奏不卡
字幕不挡脸
封面可读
音乐和平台可用
没有明显版权或隐私风险
```

## 和完整流程的区别

| 项目 | 轻量反抄 | 完整创作 |
| --- | --- | --- |
| 核心 | BGM + 卡点 + 情绪填空 | 主题、叙事、素材匹配、分镜 |
| 云端产物 | 轻量剪辑卡 | brief / script / storyboard / EDL |
| Mac 分析 | 可只扫素材和候选画面 | 生成 manifest、keyframes、匹配报告 |
| 剪映 | 人工快速剪 | 按 EDL / import pack 组织 |
| 适合 | 热点跟拍、低成本同款、情绪氛围短视频 | 重要项目、复杂叙事、长期资产 |
