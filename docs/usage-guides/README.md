# 08 使用指南索引

本目录放**具体情形**的日常操作指南。它不替代 `00_本地素材与剪映HyperFrames流转总纲.md`，也不替代 `01` 到 `06` 的制度型 SOP；它只把高频入口写成“现在手里有什么 -> 用哪个能力 -> 文件落到哪里 -> 下一步做什么”。

编号规则：

```text
08.01 = 一个具体使用情形
08.02 = 另一个具体使用情形
08.03 = 继续扩展
```

也就是说，`08.xx` 不是章节号，而是“情形号”。每篇指南都必须在标题里写清楚它解决的具体情形。
