项目页 · 删除作品

设计稿 · 2026-10-25 · photo-content-os 总控会话出稿 · 需求卡「Studio 项目页能批量删除作品，删掉的能恢复」（R275）。第 2 节逐处对比：左边是现在截图里的那一块，右边是这一块改好后的样子；第 3 节是改后整页和可以点的演示。截图里的照片已涂灰（私人素材不进仓库）。

一句话

项目页右上角加「选择」，勾好作品后在底部点「删除 N 件」；确认框逐件列出作品和文件夹，可以选择把没有素材的作品的文件夹一起移到废纸篓；删掉的作品先放进项目列表底部的「最近删除」，能撤销、能恢复。

1 · 交互规则

  1. 进入选择：单个项目页的右上角，在「添加作品」左边加「选择」。点了进入选择：每张卡片左上角出现勾选框，卡片下面多一行「×月×日建 · 文件夹 ××」（同名作品靠它分清）；点卡片是勾选 / 取消勾选，不再打开作品；右上角的两个按钮换成「全选」。项目列表页、工作台不加选择。
  2. 底部操作条：选择时一直浮在内容区底部中间，写「已选 N 件」，右边「取消」「删除 N 件」。一件没选时写「还没选作品」，删除按钮写「删除」并且点不了。点「取消」或按 Esc 退出选择、清空勾选。网址不变；刷新页面也退出选择。
  3. 确认框：点「删除 N 件」弹确认框。标题「删除 N 件作品？」；逐件列出作品名和「文件夹 ××」，超过 5 件时框内滚动。下面一个勾选项「同时把文件夹移到废纸篓」，每次打开都默认不勾。焦点落在「取消」上。点「取消」关框，勾选保留。
  4. 有素材的作品不能连文件夹删：选中的作品里有素材（视频或照片数大于 0）的，那一行多一句「有素材，文件夹留在原处」；全部都有素材时，「同时把文件夹移到废纸篓」点不了，说明写「选中的作品都有素材，文件夹不能从这里移走；要删素材，去素材库。」只有一部分有素材时，这一项写成「同时把 M 件没有素材的作品的文件夹移到废纸篓」。
  5. 确认删除：逐件处理，一件出错不影响别的。勾了移文件夹的，先把文件夹移到废纸篓，移成功才删作品；移不成功这件就不删。完成后退出选择、列表刷新，右下角提示「已删除 N 件作品」和「撤销」，停 8 秒；部分失败时提示改用警示色，写「已删除 N 件。「作品名」没删成：文件夹移不到废纸篓」（多件失败写「M 件没删成」），没删成的作品留在列表里。两种提示都带「撤销」，点了把这一批全部恢复（文件夹也从废纸篓放回原处）。
  6. 项目空了：一个项目里的作品全部删掉后，这个项目从项目列表里消失，页面回到项目列表。工作台「最近的作品」和「等你处理」里也不再出现删掉的作品。
  7. 最近删除：项目列表最下面一行「最近删除 · N 件」，没有删过东西时不显示。点进去按删除时间从新到旧列出：作品名；「原来在 ×× · 文件夹 ×× · ×月×日 ××:×× 删除」；文件夹状态写在下一行。每行右边「恢复」。恢复后回到原来的项目；文件夹在废纸篓的，先放回原处再恢复。
  8. 恢复不了的：文件夹已经不在废纸篓里（废纸篓清空了），或原来的位置已经有同名文件夹时，这一行写明原因，「恢复」换成「移出列表」。点了直接移出，不再二次确认，这是这一页唯一的彻底删除。
  9. 读屏：选择时卡片是 role="checkbox"，读「作品名，文件夹 ××，已选 / 未选」；操作条的件数用 aria-live="polite" 播报；确认框是模态框，关掉后焦点回到「删除 N 件」。动画只有提示的淡入淡出（沿用 .toast 的 0.15 秒），减少动画时不淡入。

7 · 实现前先立的门禁（在现在的代码上会失败）

编号门禁
G1后端单测：删除接口把作品放进「最近删除」后，作品列表、项目分组、工作台待处理都不再含它；恢复后原样回来，文档和修改记录逐字节不变。
G2后端单测：要求移文件夹时，有素材的作品、文件夹不在素材根目录下、文件夹是软链接、两件作品指向同一文件夹、文件夹就是素材根目录本身，这五种都拒绝，作品不删，文件夹不动。
G3后端单测：移文件夹失败时这件作品不删；同一批里其他作品照常删除，返回里逐件写成功 / 失败。
G4后端单测：恢复一件文件夹在废纸篓的作品时，文件夹回到原路径；废纸篓里已没有、或原路径被占用时，恢复被拒绝，返回能显示给人的原因。
G5浏览器测试：项目页有「选择」；进入选择后点卡片不跳转；勾 2 件后操作条写「已选 2 件」；确认框里「同时把文件夹移到废纸篓」默认未勾；全选有素材的作品时它点不了。
G6文案比对：实现页上出现的字都在第 5 节文案表里（check_design_contract.py）。
