# 直出黑帧检查：暗色空画面

稳定失败类为候选 `checks.blackFrames=fail`。检查原生合成画面，不拿烧录字幕充当画面内容。

低亮度本身不是失败。每帧缩至最长横向320px的分析图（保留纵横比，不放大），以通道均值≤64确认暗色范围；只有灰度标准差≤3，且去除孤立噪点后的有效边缘像素少于8，才判暗色空画面。边缘使用3×3中值滤波、FIND_EDGES阈值16，排除滤波保留的图像外框。文字笔画、少量圆点/线条即使只占很小面积也构成内容；一个编码亮点不构成内容。亮色或高饱和纯色不属于本检查的暗色空画面范围；这不是通用审美评分。

`video_black_frames.inspect_black_frames` 流式检查每一帧，记录帧号、分析尺寸、阈值、标准差与边缘量，写入本轮 `return/black-frame-check.json`。解码不足一帧、零帧或FFmpeg失败不能报通过。纯黑和纯深灰仍失败；字幕不会改变这个结果。

修复路径：先读被标记的原始帧及检查JSON。真实空画面由渲染器/素材负责人修复；合法深底内容的误判须补通用合成负例和实际帧重放后修检测器，不能将作品ID/帧号写成例外或只调亮背景。

回归：`tests/test_video_black_frames.py`、`tests/test_pf_video_pipeline.py`。本条替换旧的“98%低亮度像素即黑帧”判据，沿用原候选阻断，不增加新的发布门禁。若将来换掉空画面检测器，应同时删除本实现及对应校准说明，不留两套默认判据。
