# 视频风格库

改写自 Moessif/code-video-showcase 的风格配方（MIT），上游提交 2a5fb1f（完整提交 2a5fb1f754f988b31ff88ecb317ce282906a5488）。上游许可全文见 `LICENSE-code-video-showcase.txt`；配方原文保留在 `docs/tasks/R283-direct-style-library/reference/`。

九种都使用同一段「聚光灯效应」台词，画布 1080×1920，30 fps、360 帧；发布样张为 360×640 的无声 MP4 与最后一帧 JPG。顺序以 `index.json` 为准。底部字幕区留空。

## 改写说明

- **扁平插画（flat）**：配方是横屏 3 秒的四季太阳系卡点片；改成竖屏后把太阳系构图放大占满内容区上半，数字和胶囊标签移到下方；去掉卡点冲击、常驻旋转和标题扫光，改成跟口播逐句弹出；ZCOOL 快乐体换成锁定的华文黑体，靠黄色胶囊和珊瑚高光条保留活泼感。
- **数学动画（math）**：配方是横屏 3 秒、用圆链画心形的傅里叶片；改成竖屏后作图区放大到内容区上部，公式从右侧挪到下方；圆链改成画结论区域的边，只在出场时转一圈；公式排版库换成普通文字加矢量画的约等号；去掉右侧实时读数、底部等化器和公式呼吸发光。
- **极简发布会（launch）**：配方是横屏 3 秒的戒指发布片，用 Three.js 金属戒指；改成竖屏后戒指用画布网格自己着色画出来，放在上半屏，下方放两栏大数字；巨字从三句口号改成「以为」「实际」两个数字；戒指侧面的变色细环改成跟数字同步亮到一半和四分之一；去掉卡点重低音式的逐拍闪字，只留一次扫光。
- **手绘白板（whiteboard）**：保留暖纸、马克笔、逐笔画和沸腾线；横屏三步骤改为竖屏课堂实验加比例对照。滤镜改成固定种子的路径抖动，手写字体改为锁定黑体的轻微固定歪斜，去掉跟笔缩放和镜头移动，结尾冻结抖动。
- **赛博故障（cyber）**：保留紫粉天空、条纹日落、城市、透视网格与扫描线；将横屏展示片改成竖屏十六格比例图。去掉 HUD、时间码、滚动和每拍故障，改为出场一次短错位与顺序亮格，不用外部字体。
- **水墨国风（ink）**：保留宣纸纤维、层峦、浓淡墨迹、竖排和朱印；将横屏山水景观改成竖屏上下两条笔痕的比例对照。以多频率固定山脊替代动态 fbm，以排版替代书法字体，去掉舟鸟、漂移云雾和砸章。
- **数据可视化（dataviz）**：保留暗底紫红光雾、发光柱、玻璃注释和轻透视；横屏七条竞速改成竖屏两根同标尺对照柱，去掉年份大字、排名和年份脉冲，数字顺序落定，粒子和背景静止。
- **8-bit 像素（pixel）**：保留 FC 有限色板、低分辨率整数精灵、分层地面和逐格移动；横屏跑酷改成竖屏课堂和同学注意比例，去掉金币、分数、生命、倒计时与常驻跑动。数字自行画点阵，中文使用锁定黑体。
- **代码录屏（code）**：保留深色编辑器、语法色、行号、逐字输入和实时预览观感；将横屏文件树加左右双栏改为竖屏上代码下预览，代码压缩为五行实验数据。去掉跟光标镜头、时间轴、无关文件树和运动圆，展示代码不执行。

## 重新渲染

从软件根目录运行 `bash scripts/direct_video/render_style_sample.sh <id>`。先显式设置 `VIDEO_RENDER_PLAYWRIGHT_MODULE` 和 `VIDEO_RENDER_BROWSER`，分别指向固定版本 Playwright 模块入口和无头 Chromium 可执行文件。字体默认使用 macOS 华文黑体 Medium；其他系统以 `VIDEO_RENDER_FONT` 指定同一批准字体。使用本仓库 `.venv/bin/python`，需要 Node、FFmpeg、FFprobe。

脚本不安装依赖、不调用模型、不联网取资源、不启动 Studio。全库共用内核文件锁，排队运行；少于 3 GiB 空间时停止。单镜允许 600 秒，失败返回非零。工作区、原尺寸末帧、六帧联系表、渲染状态、输入与输出哈希均保留在 `$HOME/.photo-content-os/evidence/R283-direct-style-library/work/<id>/`。联系表对应帧 0、60、120、180、250、359，即 0、2、4、6、8.333、11.967 秒；最后一格是 12 秒片段的末帧。导出成功后删除 360 张原尺寸临时帧。

HTML 的 `window.seekFrame` 是每帧全部状态的入口；`palette`、`typeScale` 与实际画法对应，`visualGrammar` 和 `motionRules` 用于同风格新镜头。逐字输入、手绘与数值动画均由帧号决定。
