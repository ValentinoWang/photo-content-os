# 直出审美检查

准则归类自 Vincentwei1021/video-shotcraft 的 `references/aesthetic-rules.md`，
固定提交 `3ac67b75dd0b3bc2fd807c17f6b7ce35373eef3d`。
上游 Apache-2.0 许可原文见 [LICENSE-video-shotcraft.txt](../style_library/LICENSE-video-shotcraft.txt)。

「机判」只覆盖表中可从声明和镜头时长确定的部分。未标注动作类型的镜头，或用 JS、Canvas、SVG
自行绘制、合成的镜头，仍对照实拍帧审片。声音、文案和流程有些需要成片或交付材料，
统归「人工」，只用单镜 HTML 无法验收。审美建议均为 WARN。

| 上游编号 | 归类 | 检查内容与边界 |
| --- | --- | --- |
| R1 | 机判 | 标记的关键信息落定后，已声明静止区间中实际保留至少 1 秒。静止是否真实、停在哪个内容上，仍需看帧。 |
| R2 | 机判 | 已声明的飞入或滚动使用 `linear` 就提示。标记为批量入场的镜头末尾留至少 0.5 秒。非均匀错峰、加速感、物理隐喻和未声明轨迹看帧。 |
| R3 | 机判 | 已声明的开场主体动作弧至少持续 3 秒。动作完整性和真人交互速度看播放。 |
| R4 | 人工 | 要通看整片相机层冲击的使用次数、间隔和最强拍点，单镜读不到音乐与片段全量。 |
| Q1 | 人工 | 核对镜头是否复刻已有页面、截图来源与数据授权，再看自绘组件是否清楚。 |
| Q2 | 人工 | 纹理的源分辨率、透视显示倍率与字边锐度须查素材并放大实拍帧。 |
| Q3 | 人工 | 隐含的相机抖动和是否有意应逐帧看；单镜源码可能用任意绘制函数。 |
| Q4 | 人工 | 找到每次扫光实际影响的对象，核对次数、圆角裁切和回放质感。 |
| Q5 | 人工 | 判断主角有几个、注意力是否聚焦，并回看动作起承落。 |
| Q6 | 人工 | 对照文字密度判断机位，逐帧确认斜拍角度下可读。 |
| Q7 | 人工 | 物件特写的体积、环绕和材质反差要按镜头意图查看。 |
| Q8 | 人工 | 对照全片功能和能量变化，确认收尾代表元素及峰值。 |
| Q9 | 人工 | 看飞入后的真实槽位、遮挡和滚动流，源码的定位属性不能等同视觉归位。 |
| Q10 | 人工 | 版式完整、内容密度和虚构文档质感须看实拍帧并对照产品版式。 |
| Q11 | 人工 | 有效字高要在实拍像素上量，并确认对比度、透视和手机小窗可读性。静态字号不能代替。 |
| S1 | 人工 | 配乐和拟音的片种、音色需要将音轨垫进完整画面试听。 |
| S2 | 人工 | 音效钉帧、样本交替、响度和节奏需要音效排期及实际音轨。 |
| S3 | 人工 | 要对照改动前后时间线与音效表，确认画面锁定后已重钉。 |
| S4 | 人工 | 要对比真实动作和拟音的含义、持续时间及实际听感。 |
| S5 | 人工 | 包装偏移和源峰值滞后需从成片及音源测量。 |
| C1 | 人工 | 逐句对齐定稿画面、解说轨和品牌收尾例外。 |
| C2 | 人工 | 标语是否说清具体功能与收益，要读文案并对照产品简报。 |
| C3 | 人工 | 读相机、页面坐标和注记的实际投影，回看片上是否确实随主体运动。 |
| P1 | 人工 | 核对实际渲染证据并逐帧检查，HTML 声明不能证明已看图。 |
| P2 | 人工 | 查参考拆解及逐镜采用或放弃的理由。 |
| P3 | 人工 | 依赖反馈上下文、确认记录和版本记录。 |
| P4 | 人工 | 对照产品功能清单和所有镜头，识别缺功能、重复手法与重复信息。 |

标记写在实际控制动画的 HTML 中。时间使用秒，小数可用。传 `--durations` 时按实际镜头
时长裁算区间，例如时长表里的 145 帧、30 fps 是 145/30 秒。帧窗口仍由 `seekFrame` 负责绘制。

- **R1**：元素上加 `data-key-landed`，`data-motion-end` 是该元素落定的秒数。
  在 `body` 原有的 `data-hold="起-止,起-止"` 中声明对应静止区间。
  若声明了落定点却没有足够的区间，报 `aesthetic_r1_key_hold`。
- **R2**：飞入或滚动元素的 `data-motion-easing` 使用该轨迹实际读取的缓动名。
  声明 `linear` 报 `aesthetic_r2_linear_motion`。批量入场时在 `body` 加
  `data-batch-entrance`，结尾的 `data-hold` 短于半秒、未覆盖切点或读不出时
  报 `aesthetic_r2_tail_hold`。普通镜头的中段停顿不触发收尾要求。
- **R3**：该片的主体开场确实有一条动作弧时，在 `body` 写 `data-opening-arc="起-止"`。
  小于 3 秒或声明不能读取时，报 `aesthetic_r3_opening_arc`。
- **直出画布与字幕区**：`html` 或 `body` 在样式内声明固定像素宽高，
  例如竖屏 `1080px × 1920px` 或横屏 `1920px × 1080px`。
  读不到明确尺寸报 `canvas_size_unreadable` 输入错误。
  对画布坐标系内、从顶部定位的关键固定元素，可加 `data-subtitle-safe`，
  行内 `top` 和 `height` 使用 px。元素越过画布高度的 80%，或已标记却读不到固定位置，
  报 `subtitle_safe_zone`。竖屏安全区从 y=1536 开始，横屏从 y=864 开始。
  流式布局、祖先变换、描边和动态内容的实际边界仍以渲染帧为准。
