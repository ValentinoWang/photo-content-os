# 工作台输入、报错、删除确认和键盘操作的五处修复

状态：待确认

## 我的理解

1. 粘贴或输入超过上限的文字时，文字一个字不少地留在框里，框标红并写明超出多少字，不能提交。
2. 遇到页面不认识的错误时，不再说成「读不到这一镜的状态」，要写明错误码；视频播放失败写播放失败。
3. 把素材移入回收站时，用工作台自己的确认框，不再用浏览器原生弹窗。
4. 做法页签能用左右方向键切换；只有缩略图没有文字的镜头按钮，读屏能读出是第几镜（我补充的）。
5. 按钮上的文字不会被拖选中（我补充的）。

## 不做的

- 不改字号、圆角、间距这些写死的样式
- 不做组件重构和美化，那是另一张卡
- 不动主检出里还没提交的改动

## 验收标准

### H-01

怎么操作：
1. 打开一件作品，进入「脚本直出」的分镜脚本。
2. 粘贴一段超过 2000 字的文字到某一镜的台词。
3. 查看输入框和提交按钮。

应该看到：粘贴的文字全部留在框里，框变红，框下写「超出 N 字」，N 等于实际字数减 2000，提交按钮不可点；删到 2000 字以内后红框和提示消失。

### H-02

怎么操作：
1. 打开整理台。
2. 选择几项素材，点移入回收站。
3. 点确认框里的取消，再操作一次点确认。

应该看到：弹出的是工作台样式的确认框，写明要移入的项数；点取消什么都不变，点确认后素材移走。

### H-03

怎么操作：
1. 打开一件作品的页面。
2. 点「做法」页签中的一个，再按左右方向键。

应该看到：焦点和选中的页签在「按素材剪 vlog」「按脚本做视频」「脚本直出」之间跟着切换，到头后循环。
