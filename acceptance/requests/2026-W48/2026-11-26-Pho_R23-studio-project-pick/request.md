# Studio 里确认策划台作品用哪个项目

状态：待确认

## 我的理解

1. 策划台发起选项目后，在电脑 Studio 首页能选一个已有项目或新建，选完策划台那边自动变成已绑定。
2. Studio 首页待选卡和确认后的项目页来源条显示同一个作品版本。

## 不做的

- 发布与复盘
- 真实付费调用
- 策划台作品页（PG_R117）
- 作品标题和 Brief 链接由总控在后续任务补齐

## 验收标准

### H-01

怎么操作：
1. 打开策划台作品页，点击「去 Studio 选项目」。
2. 打开电脑上的 Studio 首页，查看待选卡上的作品版本。
3. 选择一个已有项目并点击「用这个项目」。
4. 打开所选项目的项目页，查看来源条和策划台的绑定状态。

应该看到：Studio 首页出现「这篇作品用哪个项目」卡，写着作品版本和剩余分钟。确认后卡片消失，策划台显示已绑定，项目页显示「来自策划台 · 第 N 版」，版本和待选卡一致。
