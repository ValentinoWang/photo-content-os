# Studio 能用 Concat 精修后回传

状态：待确认

## 我的理解

1. Studio 项目页的剪辑软件列表里能看到并选中 Concat，用 Concat 精修导出后拖回成片，Studio 读取 Concat 工程核对时间线、字幕和帧数，通过后出现候选成片。

## 验收标准

### H-01

怎么操作：
1. 打开 Studio 项目页，查看「剪辑软件」列表。
2. 点 Concat 一行的「选择」。

应该看到：Concat 排在列表第一位，附官网、源码、下载链接，点选择后显示「已选择」。

### H-02

怎么操作：
1. 选择 Concat 并点「自动出第一版」，再打开生成的工程精修、导出，然后关闭 Concat 里的这个工程。
2. 拖入导出的成片到「把导出的成片拖回这里」，点「检查这份成片」。

应该看到：候选成片出现且检查通过；如果工程还开在 Concat 窗口里，提示「请先关闭 Concat 里的这个工程再回传」，不出现候选。
