# OpenClaw Media UI 原型与落地清单

两份独立可打开的静态 HTML 文件，记录 2026-09-01 一轮设计与代码核查的产出。都是纯本地文件，双击或拖进浏览器即可查看，不需要构建、不依赖网络（Google Fonts 之外）。

## 文件

- **`openclaw-media-ui-prototype.html`** —— OpenClaw Media 桌面应用的可点击 UI 原型（登录 / 安装向导 / 本地应用 9 屏 / 网页中台）。用来探索"整理台 + 素材库 + 剪辑决策"这套新 IA，跟仓库现有的 `99_System_OpenClaw/desktop/`（Photo Content OS Studio，文档版本化编辑器）是两种不同的界面形态，不是同一界面的改版。

- **`openclaw-dev-checklist.html`** —— 把原型上的每一块承诺对照本仓库 `@4da5213` 的真实代码，逐条判定「可直接接 / 需补后端 / 需先拍板 / 原型要改」，共 45 条，均标注真实文件路径。三条原本待拍板的决策（整理台自动分批、素材库结构化索引、转写默认 provider）已在同一轮里定案，见清单第 00 节。

## 怎么用

用浏览器直接打开这两个文件即可；清单支持按判定筛选，勾选进度存在浏览器本地（不会跨设备同步）。

这两份文件是设计阶段产出，不是可执行代码，不影响仓库现有测试和 CI。
